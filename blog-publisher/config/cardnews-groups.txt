# cardnews-groups.txt — 일반화 게이트 TIER-1 의 **사람 축**(성별·연령·유형)
#
# 2026-07-31 버티컬 전환(세계 문화 → 책 인용 위로). 막아야 할 문형은 구조가 같고 축만 다르다.
#   기존: "일본 사람들은 다 ~하다"      신규: "여자들은 다 ~하다" · "INFP는 항상 ~"
# 구 국명 축은 `config/cardnews-countries.txt.worldculture.bak` 로 보존한다 — 이 채널은
# 버티컬을 이미 한 번 갈아탔고, 되돌릴 수 있어야 한다.
#
# 한 줄 = 한 축 항목의 표기 변이를 `|` 로 이은 정규식 조각. 게이트가 전체를 `(A|B|…)` 로 묶어
# `${G}` 자리에 끼운다. `#` 주석·빈 줄 무시, 컴파일 실패 줄은 graceful skip
# (`scripts/gates/check-banned.mjs:23-45` 파싱 관례 그대로).
#
# 🔴 목록에 넣어도 되는 말의 기준 — **조사 `은/는` 이 바로 붙었을 때 반드시 집단 전체를
#    가리키는 말만.** 개인을 가리킬 수 있는 말(할머니·아저씨·막내·장남)은 넣지 않는다:
#    "할머니는 늘 나를 안아주셨다"가 차단되면 이 채널의 정상 문장이 매일 죽는다.
#    ("그 남자는 떠났다" 처럼 지시관형사가 붙은 개인 지칭은 코드가 `NOT_INDIVIDUAL` 로
#     따로 배제하고, TIER-2 경고로 흘려보낸다.)
#
# ⚠ `사람`·`인간`·`친구` 는 **일부러 넣지 않았다** — TIER-1 은 좁아야 한다. 축이 없는
#   "사람들은 다 똑같다" 류는 TIER-2(W2·W3)가 경고로 받는다.
